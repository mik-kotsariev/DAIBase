# DaiBase 

**DaiBase** — це десктопний застосунок на базі Windows Forms (C#) для ведення бази даних транспортних засобів, обліку їхніх власників та контролю термінів проходження технічного огляду (ТО).

## Особливості та функціонал

- **Облік транспортних засобів:** Додавання, редагування та видалення інформації про легкові й вантажні автомобілі, мотоцикли та причепи.
- **Управління власниками:** Прив'язка транспортного засобу до власника (ПІБ та номер документа).
- **Контроль техогляду:**
  - Колірна індикація в таблиці для автомобілів із простроченим ТО (якщо з дати останнього огляду минуло понад 2 роки).
  - Швидкий фільтр для відображення всіх ТЗ із простроченим технічним оглядом.
  - Генерація офіційного повідомлення (довідки) для власника про необхідність оновити ТО.
- **Розумний пошук:** Пошук за базою даних за державним номером, ПІБ власника або маркою автомобіля.
- **Валідація даних:** Перевірка правильності введення державного номера (формат АХ 1234 СВ), номера паспорта (6 цифр) та року випуску під час реєстрації або редагування.
- **Збереження даних:** Усі дані локально зберігаються у файл `data.json`, що дозволяє не втрачати інформацію після закриття програми.

## Технології

- **Мова програмування:** C#
- **Платформа:** .NET / Windows Forms
- **Збереження даних:** JSON (`System.Text.Json`)
- **Архітектура:** Розділення логіки на шари (Моделі, Сервіси, Форми) для зручності підтримки та розширення коду.

## Структура проєкту

- `Models/` — класи даних (`Vehicle`, `Owner`), перерахування типів ТЗ.
- `Services/` — бізнес-логіка застосунку.
  - `VehicleRepository` — управління колекцією автомобілів (CRUD операції, пошук, фільтрація).
  - `JsonDataStorage` — логіка збереження та читання даних із JSON-файлу.
- `Forms/` — графічний інтерфейс користувача.
  - `MainForm` — головне вікно з таблицею, пошуком та основними кнопками керування.
  - `VehicleForm` — вікно для додавання та редагування інформації про ТЗ.
  - `VehicleDetailsForm` — картка з детальною інформацією про вибраний автомобіль.

## Як запустити проєкт

1. Склонуйте репозиторій із проєктом на свій комп'ютер.
2. Відкрийте файл рішення (`DaiBase.sln` або `DaiBase.slnx`) у **Visual Studio 2026**.
3. Переконайтеся, що у вас інстальовано компонент розробки класичних застосунків .NET (Windows Forms).
4. Натисніть клавішу `F5` або кнопку **"Пуск"** (Start) на верхній панелі для компіляції та запуску.
5. При першому запуску програма автоматично створить файл `data.json` у папці з виконуваним файлом для збереження ваших записів.
